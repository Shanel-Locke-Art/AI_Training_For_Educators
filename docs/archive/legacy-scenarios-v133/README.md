# PromptCraft legacy scenarios v133

This folder contains the unmodified v133 source before Scenarios 2–8 were removed from the active runtime.

Use it only as a design and implementation reference. These files are not loaded by `index.html`. Scenario 1 and the shared application systems remain active in v134.

Archived systems include the earlier implementations of:

- S2 Metacognition workbench
- S3 Authentic Assessment prompt flow
- S4 Synchronous Bias
- S5 Hallucination Hunt
- S6 Predict the Output
- S7 Overreliance
- S8 Reflect and Revise
- Their scenario-specific dialogue, dev shortcuts, data-scoring assumptions, and CSS
